# PRD: [제품 이름]

> PRD(Product Requirements Document)는 "무엇을, 누구를 위해, 왜 만드는지"를 정리한 문서입니다.
> 각 항목의 안내 문구를 지우고 내 내용으로 채워 주세요.

- 작성자: 김대희
- 작성일: 6/10/26
- 버전: v0.1

---

1. 문제정의 (Problem) 

누가(who): 직장인, 공장노동자, 학생, 공공시설 이용자 

언제(when): 시설 이용 시간

무엇 (what): 공공시설, 오피스, 공장 과 같은 실내 이용시설의 환경 조건(온도,습도)을 수동으로 조절하게 되면 오는 불편한과 에너지 비효율성으로 우리사회가 겪는 비용의 문제 

목표 (Goal): 실내공간의 환경 조건을 각 인원수에 맞게 자동으로 조절


2. 사용자 시나리오 (User Scenario)

    1. 상황에 따른 인원이 각 실내 시설에 입장한다
    2. 카메라를 통해 ai가 인원수를 파악한다 
    3. 자동으로 적정 온도를 조절한다 
    4. 모든 인원이 퇴장할시 자동으로 환경조절 시스템 또한 종료된다 

3. 성공지표 (KPI)

    1. 인원파악 분석 시간 5초 이내 
    2. 환경 시스템 (에어콘) 온도 조절 시간 5초 이내 
    3. 환경 시스템 온도 유지 안정성 (2시간 이상)
    4. 인원 퇴장시 환경시스템 종료 시간 5초 이내
    5. 네트워크 연결 안정성 (2시간 이상)

4. 기술 스택 (Technology Stack)

    1. Bluetooth 5.4 통신 
    2. ARM 기반 저전력 MCU
    3. Android/IOS 지원 

5. 범위 비범위 (Scope/ Out of Scope)

    포함 (Scope)

    인원 체크 
    온도 체크/조절
    습도 체크/조절
    Bluetooth 자동 연결 

    제외 (Out of Scope)

    인원 신원 파악 
    음성 기능
    동물 확인


6. ROI 현황

    투자비용: 개발비 5억원 
    예상 판매량: 연간 10,000대
    예상 순이익: 연간 8 억원 
    ROI = (8억-5억)/5억 x 100 = 60%
    
    결론: 투자 대비 경제성이 있어 양산 검토 가능
