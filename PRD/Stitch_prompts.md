
OccuCool(오큐쿨)이라는 제품의 한국어 데스크톱 웹사이트 랜딩 페이지를 디자인해줘. OccuCool은 천장에 설치하는 엣지 AI 컨트롤러로, 카메라로 공간 안의 인원수를 파악해서 에어컨 온도와 풍량을 자동으로 조절하고, 사람이 모두 나가면 자동으로 절전하는 B2B 제품이야. 주요 고객은 사무실, 학교, 공공시설의 시설 관리자야. 모든 텍스트는 한국어로 작성해줘.

디자인 스타일은 깔끔하고 신뢰감 있는 B2B 테크 느낌이야. 배경은 흰색과 연한 회색을 쓰고, 주색은 딥 블루, 포인트 색은 따뜻한 오렌지로 해서 '차가움과 따뜻함', 즉 온도를 표현해줘. 폰트는 Noto Sans KR, 카드는 둥근 모서리(rounded-2xl)와 부드러운 그림자, 아이콘은 얇은 라인 스타일, 여백은 넉넉하게 해줘.

페이지는 위에서 아래로 이렇게 구성해줘.

1. 상단 내비게이션 바: 왼쪽에 OccuCool 로고, 가운데에 '제품 소개', '작동 원리', '기대 효과', '기술 사양', '문의' 메뉴, 오른쪽에 오렌지색 call-to-action 버튼 '도입 문의하기'.

2. 히어로 섹션: 큰 헤드라인 '사람이 있을 때만, 딱 필요한 만큼', 서브카피 '카메라 AI가 인원수를 읽고 냉난방을 자동으로 조절합니다. 영상은 기기 안에서만 처리됩니다.', 버튼 두 개('도입 문의하기' 오렌지 채움 버튼, '작동 원리 보기' 아웃라인 버튼). 오른쪽에는 천장에 설치된 작은 원형 컨트롤러가 있는 밝은 사무실 일러스트와, 그 위에 떠 있는 상태 카드('현재 인원 8명 · 설정온도 25℃ · 절전 모드 해제')를 배치해줘.

3. 문제 섹션 '이런 낭비, 아직도 겪고 계신가요?': 카드 3개로 '고정 스케줄 타이머는 실제 재실과 무관하게 작동', '모션센서는 가만히 앉아 있으면 공실로 오판', '수동 조작은 퇴근 후 끄는 것을 놓치기 쉬움'을 보여줘.

4. 작동 원리 섹션: 4단계 스텝 레이아웃으로 '1. 인원 감지 → 2. AI 분석 → 3. 자동 제어 → 4. 리포트 확인'을 가로로 연결하고, 각 단계에 아이콘과 한 줄 설명을 넣어줘.

5. 핵심 기능 섹션: 2x2 카드 레이아웃으로 '5초 이내 인원 변화 감지', '영상 비저장·외부 전송 없음', '네트워크가 끊겨도 기기 내 자동 제어', '다양한 에어컨 연동(IR, Modbus, BACnet)'을 보여줘.

6. 숫자로 보는 효과 섹션: 큰 숫자 3개를 가로로 배치해줘('최대 15% 에너지 절감', '5초 이내 인원 변화 감지', '영상 외부 전송 0건'). 연한 파란 배경 띠로 구분해줘.

7. 활용 공간 섹션: 사무실, 학교, 공공시설 3개 카드, 각각 대표 이미지와 한 줄 설명.

8. 도입 문의 섹션: 왼쪽에 안내 문구, 오른쪽에 문의 폼(회사명, 담당자명, 이메일, 연락처, 공간 면적, 에어컨 종류 드롭다운, 문의 내용, 오렌지색 '문의 보내기' 버튼).

9. 푸터: 로고, 회사 정보, 개인정보처리방침 링크, 저작권 문구.
