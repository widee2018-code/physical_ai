# OccuCool 모바일 앱 — Stitch 프롬프트

index.html에 설명된 OccuCool 제품을 스마트폰 앱으로 제어하기 위한 화면 설계용 프롬프트입니다.
[Google Stitch](https://stitch.withgoogle.com/)에서 Mobile 모드로 사용합니다.

## 1. 앱 기능 구성 (index.html 내용 기반)

| 화면 | 핵심 기능 | 근거가 된 제품 특성 |
|---|---|---|
| 홈 대시보드 | 구역별 재실 인원, 실내 온습도, 설정온도, 운전 상태(자동/수동/절전/안전모드) | 구역별 인원 계수, 재실 상태 머신 |
| 구역 상세·수동 제어 | 전원·온도·풍량·모드 조절, "2시간 후 자동 복귀" 안내 | 사람이 조작하면 2시간 우선한 뒤 자동 복귀 |
| AI 판단 기록 | "8명 감지 → 6~10명 구간 → 25°C, 풍량 증가" 같은 설명 | 인원 구간별 제어 기준 |
| 자동 제어 규칙 | 인원 구간별 온도·풍량, 공실 유예 10분, 절전 방식(OFF 또는 +2°C), 운영 스케줄·공휴일 | 현장에서 조정 가능한 기준값 |
| 알림 센터 | 긴급(제어 실패, 카메라 가림)은 푸시로, 주의는 일일 요약으로 | N1 알림 정리 |
| 에너지 리포트 | 절감률, kWh, 공실 시간, 수동 조작 횟수, 월간 설정 제안 승인 | L2 KPI, L4 월간 리포트 |
| 기기 상태 | 온라인 여부, 카메라 상태, 오프라인 버퍼, "영상 외부 전송 0건" 표시 | 프라이버시, D1 영상 건전성, N2 오프라인 버퍼 |
| 기기 등록 | QR 스캔, Wi-Fi 연결, 에어컨 연동 방식(IR, Modbus, BACnet), 구역 이름·면적 입력 | 설치 과정 |

## 2. Stitch 프롬프트

**사용 순서:** Stitch는 한 번에 화면 하나를 만들 때 결과가 가장 좋습니다. 먼저 ①번 기본 프롬프트로 디자인 톤과 홈 화면을 잡으세요. 그다음 같은 프로젝트 안에서 ②~⑧번을 하나씩 추가하면 스타일이 통일됩니다.

### ① 기본 프롬프트 (디자인 시스템 + 홈 대시보드)
```
OccuCool(오큐쿨)이라는 스마트 냉난방 제어 기기를 관리하는 한국어 모바일 앱(iOS/Android)을 디자인해줘.
OccuCool은 천장에 설치하는 엣지 AI 컨트롤러로, 카메라로 구역별 재실 인원을 세서 에어컨의 전원·온도·풍량을 자동 조절하고, 사람이 모두 나가면 10분 뒤 자동 절전해. 영상은 기기 안에서 바로 지우고 인원수만 남겨. 사용자는 사무실·학교·공공시설의 시설 관리자야. 모든 텍스트는 한국어로 써줘.

디자인 스타일: 어두운 네이비 배경(#070D18), 카드 배경 #0E1726, 구분선 #1E2A3D. 냉방·AI 강조색은 스카이 블루(#38BDF8), 경고·열부하는 오렌지(#FB923C), 정상 상태는 그린(#34D399). 폰트는 Pretendard, 숫자는 크고 굵게, 카드는 둥근 모서리 14px, 얇은 라인 아이콘. 하단 탭바: 홈, 리포트, 알림, 설정.

첫 화면은 '홈 대시보드'야.
- 상단: 건물명 '본사 3층', 오늘 절감률 배지 '오늘 12% 절감', 알림 벨 아이콘
- 요약 띠: 총 재실 23명 · 가동 중 3대 · 절전 중 1대
- 구역 카드 목록(세로 스크롤). 각 카드에 구역명, 큰 숫자로 재실 인원, 실내온도/설정온도, 풍량 아이콘, 상태 칩(자동 제어=파랑, 수동 조작 중=오렌지, 절전=회색, 안전 모드=빨강)
  예: 'Zone A 사무실 8명 · 실내 26.4°C → 설정 25°C · 자동', '대회의실 0명 · 절전 전환까지 6분', '소회의실 3명 · 수동 조작 중(1시간 32분 후 자동 복귀)'
- 각 카드 오른쪽에 전원 토글
```

### ② 구역 상세·수동 제어
```
같은 디자인으로 'Zone A 사무실' 구역 상세 화면을 만들어줘.
- 상단: 큰 숫자 '8명 재실 중'과 150㎡ 좌석 점 그리드(재실 자리는 스카이 블루로 빛남), 마지막 감지 '3초 전'
- 3칸 수치: 실내온도 26.4°C / 습도 52% / 인체 발열(추정) 880W
- AI 판단 카드: '6~10명 구간입니다. 기본 26°C에서 1°C 낮추고 풍량을 올립니다.'
- 수동 제어 영역: 원형 온도 다이얼(18~30°C), 풍량 4단계 세그먼트(자동/약/중/강), 모드(냉방/난방/송풍/제습), 큰 전원 버튼
- 수동 조작 시 하단 안내 바(오렌지): '수동 설정이 2시간 동안 우선 적용된 뒤 자동 제어로 돌아갑니다' + '지금 자동으로 복귀' 버튼
- 보호 규칙 안내 문구: '설비 보호를 위해 설정 변경은 5분 간격, 시간당 4회까지 적용됩니다'
- 하단: 오늘 24시간 재실 인원(막대)과 실내온도(선)를 겹친 차트
```

### ③ 자동 제어 규칙 설정
```
같은 디자인으로 구역별 '자동 제어 규칙' 설정 화면을 만들어줘.
- 냉방/난방 탭 전환 (기본 설정온도 냉방 26°C, 난방 22°C)
- 인원 구간별 규칙 리스트 4행, 각 행에 설정온도 스테퍼와 풍량 선택:
  0명 → 절전 / 1~5명 → 26°C 기본 풍량 / 6~10명 → 25°C 풍량 증가 / 11명 이상 → 24°C 풍량 최대
- 공실 처리: 공실 확정 후 유예시간 슬라이더(5~30분, 기본 10분), 절전 방식 선택(바로 끄기 / 설정온도 +2°C 후 끄기)
- 운영 스케줄: 요일별 운영 시간 칩, 공휴일 자동 적용 토글, 출근 전 미리 냉방 토글(30분 전)
- 하단 고정 '저장' 버튼(스카이 블루)과 '기본값으로 되돌리기' 텍스트 버튼
```

### ④ 알림 센터
```
같은 디자인으로 '알림' 화면을 만들어줘.
- 상단 필터 칩: 전체 / 긴급 / 주의 / 정보
- 알림 카드: 왼쪽 컬러 바(긴급=빨강, 주의=오렌지, 정보=파랑), 제목, 구역명, 시간, 상태(진행 중 / 해소됨)
  예: '긴급 · 대회의실 카메라 가림 감지 — 공실 판정을 보류했습니다'
      '긴급 · Zone A 에어컨 명령 실패 3회 — 현장 확인이 필요합니다'
      '주의 · 소회의실 운영 시간 외 재실 감지 (21:40)'
      '정보 · 어제 에너지 14% 절감 리포트가 준비됐습니다'
- 해소된 알림은 흐리게 표시하고 '해소됨' 체크 배지
```

### ⑤ 에너지 리포트
```
같은 디자인으로 '에너지 리포트' 화면을 만들어줘.
- 기간 세그먼트: 일 / 주 / 월
- 상단 큰 숫자 카드: '이번 달 15.2% 절감', 절감 전력 412kWh, 예상 절감액 ₩98,000
- 도입 전 기준선과 실제 사용량을 비교하는 막대 차트 (날씨 보정 기준선 표시)
- KPI 리스트: 쾌적도 유지율 92%, 공실 시간 비율 27%, 수동 조작 횟수 14회(지난달 대비 −48%), 제어 성공률 99.6%
- 'AI 제안' 카드: '대회의실은 회의 사이 공백이 평균 18분입니다. 공실 유예시간을 10분에서 15분으로 늘리면 재가동이 줄어듭니다.' + '적용' / '무시' 버튼
- 'PDF로 내보내기' 버튼
```

### ⑥ 기기 상태·프라이버시
```
같은 디자인으로 '기기 상태' 화면을 만들어줘.
- 기기 카드: 'OccuCool-A01 · Zone A', 온라인 초록 점, 펌웨어 v1.2.0
- 상태 리스트(아이콘+값+상태 점): 카메라 영상 상태 정상, AI 추론 속도 142ms, 기기 온도 48°C, 에어컨 연동 IR · 마지막 확인 12초 전, 네트워크 Wi-Fi 강함, 오프라인 저장 대기 0건
- 프라이버시 배지 카드(그린 테두리): '영상은 기기 안에서 바로 지워집니다 · 이번 달 영상 외부 전송 0건'
- 하단 버튼: '기기 재시작', '카메라 위치 점검', '지원 요청'
```

### ⑦ 기기 등록(온보딩) – 단계형 4화면
```
같은 디자인으로 새 OccuCool 기기 등록 과정을 4단계 화면으로 만들어줘. 상단에 진행 표시(1/4).
1단계: 기기 뒷면 QR 코드 스캔 카메라 뷰
2단계: Wi-Fi 선택과 비밀번호 입력
3단계: 에어컨 연동 방식 선택 카드(IR 리모컨 신호 / Modbus / BACnet)와 '테스트 신호 보내기' 버튼
4단계: 구역 이름, 면적(㎡), 공간 유형(사무실/회의실/교실/공공시설) 입력 후 '등록 완료' 축하 화면
```

### ⑧ (선택) 홈 화면 위젯·잠금화면 알림
```
같은 디자인으로 iOS 홈 화면 위젯 2종(소형: Zone A 8명·25°C·자동 / 중형: 구역 3개 요약과 오늘 절감률)과 잠금화면 푸시 알림 예시 '긴급 · 대회의실 카메라 가림 감지'를 한 화면에 보여줘.
```

## 3. Stitch를 쓸 때 참고할 점

- **수정은 짧게 요청하세요.** 결과가 나온 뒤에는 "온도 다이얼을 더 크게", "상태 칩 색만 바꿔줘"처럼 한 번에 한 가지만 요청하는 게 좋습니다. 처음 프롬프트를 통째로 다시 넣으면 디자인이 처음부터 다시 만들어집니다.
- **수치는 그대로 두세요.** 프롬프트의 숫자(26°C, 10분 유예, 5분 간격, 시간당 4회)는 index.html의 제어 기준에서 가져왔습니다. 그대로 쓰면 앱과 랜딩 페이지 내용이 맞습니다.
- **색상은 의도적으로 index.html을 따랐습니다.** 기존 `stitch/occucool-landing`의 밝은 딥블루·오렌지 테마 대신 index.html의 다크 네이비·스카이블루 색상을 썼습니다. 랜딩 페이지 톤에 맞추고 싶다면 ①번의 색상 줄만 `stitch/occucool-landing/DESIGN.md`의 primary `#00162d`, secondary `#fd651e`로 바꾸세요.
- **한국어 문구가 깨질 때:** 한국어 문구가 깨지거나 영어로 바뀌면 프롬프트 끝에 "All UI text must be in Korean."을 덧붙이세요.
