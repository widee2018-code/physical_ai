## 6. 에어컨(HVAC) 조건

→ 전처리 근거: 유형별 냉방 응답 지연이 달라 인원·온도 변화와 제어 효과 간 시간 지연(Lag) 보정값을 정한다.

→ 전처리 근거: 구역별 인원수를 에어컨 단위 제어 입력으로 집계(Aggregation)하는 규칙을 정한다.

### 6-3. 제어 인터페이스

→ 전처리 근거: IR 단방향이면 실제 상태 피드백이 없으므로 명령 로그 기반 상태 추정(State estimation)이 필요하다.

→ 전처리 근거: 사람이 리모컨으로 수동 변경한 이벤트를 감지·라벨링하여 학습/제어 데이터에서 분리할지 결정한다.

### 6-5. 수동 조작 빈도

### 6-6. 압축기 보호/최소 운전 조건
