
1. checklist prompt

[역할]
너는 피지컬 AI, 컴퓨터 비전 및 데이터 전처리 분야의 최고 기술 전문가야.

[목적]
나는 [농지 잡초 제거 피지컬 AI 로봇] 개발을 진행하고 있어.
[잡초인지 잡초가 아닌지를 판단하는 AI를 만들거야]
나중에 현장 조사 결과를 가지고 너에게 '최적의 데이터 전처리 기법 및 전처리 순서'를 물어보려고 해.

그 질문을 정확하게 하기 위해, 먼저 내가 현장에 나가서 조사해야 할 **'통합 현장 조사 가이드(체크리스트)'**를 만들어줘.

[가이드 작성 조건]
1. 현장에서 가장 쉽고 빠르게 기록할 수 있도록 항목별 특성에 맞춰 '객관식 선택 [v]' 방식으로 작성해줘.
2. 각 항목마다 "이 정보가 추후 데이터 전처리 알고리즘/필터 설정에 왜 필요한지" 1문장으로 짧게 설명을 덧붙여줘.

[출력 형식]
- 현장에서 노션, 엑셀, 수첩 등에 바로 입력하기 편하게 마크다운 코드 블록 양식으로 작성해줘.
- 가이드 생성이 끝난 후, 조사한 데이터를 바탕으로 너에게 어떤 전처리 과정이 좋은지를 물어볼 때 사용할 '최종 질문 프롬프트 예시'도 함께 작성해줘.  


2. preprocess_report prompt 

[역할]
너는 피지컬 AI, 컴퓨터 비전, 시계열 센서 데이터 전처리 분야의 최고 기술 전문가야.

[제품 개요]
OccuCool(오큐쿨) – 재실 인원 기반 냉난방 자동 제어 엣지 AI 컨트롤러
- 입력: 천장 카메라 영상(기기 내 처리, 저장 안 함)에서 추출한 구역별 인원수, 실내 온습도, 에어컨 상태(전원·설정온도·모드), (선택) 외기온도·운영 스케줄
- 출력: 에어컨 제어 명령(전원·설정온도·풍량·모드), 습도 이상 시 제습 전환, 이상 알림, 인원·온습도·에너지 로그 및 대시보드
- 엣지 디바이스: [예: Jetson Orin Nano / Raspberry Pi 5 + Hailo-8 등]

[조사 결과]

[요청 사항]
위 현장 조건을 바탕으로 다음을 제시해줘.
1. 데이터 소스별(① 카메라 영상 ② 인원수 시계열 ③ 온습도 센서 ④ 에어컨 상태/명령 로그 ⑤ 외기·스케줄 ⑥ 에너지) 최적의 전처리 기법과 그 선정 이유
2. 원시 데이터 입력부터 제어 모델 입력까지의 전체 전처리 순서(파이프라인)를 단계별로 정리하고, 순서가 바뀌면 안 되는 이유
3. 각 필터의 초기 파라미터 권장값(예: 이동평균 윈도우, 이상치 임계값, debounce 시간, 리샘플링 주기, 히스테리시스 폭)과 현장 튜닝 방법
4. 멀티모달 데이터 시간 동기화 및 결측 처리 전략
5. 엣지 연산 자원 제약을 고려해 실시간 처리 가능 여부와 경량화 방안
6. 이 현장에서 예상되는 주요 오탐/오제어 위험 요인 Top 5와 대응 전처리 방법
7. 조사 결과 중 정보가 부족하거나 추가 확인이 필요한 항목

[출력 형식]
- 파이프라인은 단계 번호와 함께 표로 정리
- 파라미터는 "권장값 / 조정 범위 / 조정 기준"으로 구분
- 추가 조사가 필요한 항목은 마지막에 별도로 정리
